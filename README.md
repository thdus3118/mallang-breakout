# 말랑 벽돌깨기

말랑이를 튕겨서 사탕 벽돌을 깨는 귀여운 벽돌깨기 게임입니다.

▶ **플레이:** https://thdus3118.github.io/mallang-breakout/

## 조작
- 마우스 / 터치 드래그 / ← → (A, D): 고양이 패들 이동
- 클릭 / 터치 / 스페이스: 시작 · 발사
- P 또는 Esc: 일시정지 · M: 소리 끄기/켜기

## 아이템
- ♥ 하트: 생명 +1
- ★ 별: 말랑이 분신술 (공이 늘어나요)
- 🐟 물고기: 10초 동안 패들이 커져요

크림 얹은 벽돌은 두 번 맞혀야 깨져요.
